# 评估依据与数据规则

[返回项目说明](../README.md) · [使用手册](user-guide.md) · [家长写作规则](parent-feedback-writing.md)

本系统评价指定学习时段内已提供的成果，形成训练参考。内部保留专业分析与来源，家长正文只汇报实际表现、能力和下一步安排。

## 不同材料怎样使用

| 材料 | 可支持的结论 | 不应直接推出的结论 |
| --- | --- | --- |
| 讲师确认的限时独立比赛 | 对应题目中的独立理解、设计、实现及赛场能力 | 陌生题也一定会做、没有失误、一定获奖 |
| 先尝试后讲解的课堂作业 | 早期思路、实际完成部分、后续修改与吸收 | 最终 AC 就是独立完成、第一次 AC 前一定未讲解 |
| OI/CSP 最终提交 | 最终作品及平台给出的分数、部分分 | 只尝试了一次、没有检查、没有修改 |
| 明确时间的多次提交 | 具体版本变化、对应原始代码的结果 | 次数越多越勤奋、间隔就是连续做题耗时 |
| 未提交题面 | 任务覆盖范围及需要进一步确认的内容 | 不会做、懒惰、专注不足、知识分为零 |
| 时间未核实的额外快照 | 保留供讲师查看 | 自动计入本期完成成果 |
| 更早已确认的真实反馈 | 历史能力背景、CSP 对照参考 | 替代本期知识掌握证据 |

手动改过主代码后，原提交成绩不适用于这段新代码；系统保留原提交及其结果，阻止把原 AC 继承给修改后的作品。平台程序运行时间和相邻提交间隔，与讲师明确记录的学生实际做题耗时分开。

姓名与平台账号用于作品归属核对，内部比赛排名不作为实力依据。同一道公开题出现在不同作业或比赛中，保留不同场景，但不能把重复练习夸大成多道陌生题迁移。

## 知识掌握与能力评分

知识词表在 `data/public/topics.json`，目前为 46 项常用标签，是洛谷标签的整理子集。API 从预设编号选择，不临时创造图表维度。全部本期知识评分保留；主图取有效分数最高六项，按标签编号排列，同分以编号确定顺序。一两项用条形图，没有有效分数显示材料不足。

| 分值 | PDF 注解 | 内部需要的依据 |
| --- | --- | --- |
| 1—20 | 能理解老师讲的 | 有理解相关概念的材料 |
| 21—40 | 在提示下能完成练习 | 已知提示下的实际应用 |
| 41—60 | 能独立做基础题 | 独立完成基础应用的证据 |
| 61—80 | 能独立做综合题 | 独立综合应用的证据 |
| 81—100 | 能灵活运用讲清做法 | 未见变式应用与方法说明的条件证据 |

材料不足用 `null`，不补造分数。雷达图只表现本期已有依据的强项，不是所有知识点的完整画像，也不直接换算 CSP 分数。讲师可以审核改分，系统增加 `teacher:review` 依据并保存版本。

六项能力固定为阅读理解、分析推理、方案设计、编程实现、检查改进、专注投入。前五项由 API 按题面、代码、结果和明确观察分析；专注投入首次生成只采用讲师分，未填就不评分。代码格式、命名或提交次数不能直接证明人格、专注力或比赛得分。

后续分析自动引用最多八份更早时段、有确认版本的真实报告；本期开始前尚未结束、重叠时段、演示反馈和未确认草稿不作为历史。生成时固定历史快照，恢复不会随历史库变化偷偷替换依据。

## CSP 等级怎样形成

1. 对所选 J / S 组别读取全部已开放参考卷。
2. 结合本期成果、完成条件和历史背景，逐题估计该卷上的保守得分区间；内部保留推断理由与假设。
3. 将各卷得分下界与**同年度广东**一级、二级、三级线比较。未知省线不编造。
4. 综合有依据的各年度定位，采用较保守的等级；家长显示“一等 / 二等 / 三等”，没有足够条件时不强给等级。

当前覆盖 2019—2025 J/S 共 14 套卷、58 道题。2019 S 为两天、每天 210 分钟、各三题，满分 600；其他卷保留各自时限与计分条件。2019 广东 J 为 250 / 100 / 70，S 为 255 / 110 / 80，核对记录见[2019 广东分数线依据](../data/public/verification/2019-guangdong-grade-lines.json)。其他年度及公告来源在 [rules.json](../data/public/rules.json)。

这一定位用于相近难度、正常发挥并符合第二轮资格时的训练参考，当前没有真实赛场回测校准。独立比赛材料对定位更有参考价值；只有讲解后完成或材料稀少时，分析需保留限制。家长 PDF 不展示内部预测分数或全部假设，讲师审核页保留依据。

## 真题审核和开放条件

题面、候选题解、知识标签及来源在 [problems.json](../data/public/problems.json)。AI 将公开题面与交叉来源核对，检查解法论证、复杂度、计分与部分分规则，保存审核版本、内容指纹和结论。审核记录在 `data/public/audits/`，原始交叉资料在 `data/public/raw/statement-crosschecks/`。

修改题面、题解、标签或计分条件使原指纹失效。仅将状态写为 `reviewed` 不能开放：必须有有效的本版 AI 审核，或讲师明确复核当前资料。**目录中所有真题审核有效后**才开放历年参考库；任一失效时新分析暂不使用参考卷。旧反馈保留自己的参考卷与规则快照，不因库更新改写。

截至 2026-10-09，58 / 58 已完成 AI 交叉审核；2026 第二轮尚未举行，系统不预设未来题目与等级线。审核是来源核对和静态推理，不等同官方认证或官方测试数据全部通过，本机也不执行参考程序。公开题目和第三方题解的来源、许可范围逐条记录，维护时应保留这些字段。

## 训练与家长表达

规划从资料基准日期出发，止于目标 CSP 已公布日期，并给最近 2—4 周重点；未公布未来日程只作阶段安排。推荐只从已核实 ACGO 题单选择，当前 40 份、849 条成员记录、832 道不同题目。按实际需要决定数量，不强制两份、不列题单内具体题号，不声称整个题单都是未见新题。

第一原则是家长听得懂。成果和能力肯定必须来自实际材料，未知过程不编成优点；自然承接后续建议，不解释算法、不做生活类比。完整 A 版口吻与提示词落实见[家长反馈写作规则](parent-feedback-writing.md)。深圳自招暂不分析或展示；相关字段只是预留数据接口。
