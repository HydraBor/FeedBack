# 家长反馈写作规则

[返回项目说明](../README.md) · [评估依据](assessment.md) · [开发说明](development.md)

家长需要读到：孩子本期做到了什么，体现了哪些实际能力，下一步准备怎么练。正文不承担题目清单或算法诊断的作用。

## 查阅的资料

- [NSW 教育部门：Writing report comments](https://education.nsw.gov.au/teaching-and-learning/curriculum/reporting-to-parents/report-comments)：使用日常语言，避免课程术语；以本期证据为依据，写出具体表现和可执行的改进方向。这里借鉴其写作方式，CSP定位仍遵循本项目已有的训练评估规则。
- [AERO：中学阶段与家长沟通](https://www.edresearch.edu.au/guides-resources/practice-guides/engaging-families-support-student-learning-secondary-school)：更新宜简短、积极、针对学生本人的学习，并让家长有机会反馈。
- [EEF：Communicate effectively with families](https://educationendowmentfoundation.org.uk/education-evidence/leadership-and-planning/supporting-attendance/communicate-effectively-with-families)：沟通围绕学习，体现具体学生的情况，肯定有依据的成果。

这些资料支持表达方式，不替代学生作品分析，不要求家长教算法，也不作为广东竞赛标准的依据。

## 在本项目中的落实

1. 内部分析保留题名、题面、代码和专业诊断；家长写作阶段的作品清单改用材料序号，提供完成情况及经过核对的比赛场数。
2. 逐题诊断增加独立的 `parent_observations`，保存家长能懂的具体表现。写作时优先使用这些表现；旧档案没有该字段时使用已保存的诊断，不要求重新逐题分析。选取能力表现时兼顾有依据的比赛与课堂成果，每项注明完成条件，避免把课堂结论移到比赛。
3. 成果摘要约140-180字，AI写作校验上限240字；讲师仍可手动扩写，报告保留分页能力。能力表现默认四项，避免重复摘要或把同一修改拆成多项。
4. 原题名、逐题清单、代码版本统计、解法术语、程序实现细节及分析报告口吻显示文案提醒，交由讲师手动修改，不触发自动重新生成，也不阻止保存、确认或下载。做题称“题目”，不用“任务”；“稳”类措辞约束覆盖标题、摘要、能力表现和建议，知识图表及题单名称不受正文词语检查影响。
5. 课堂完成条件未知时，只肯定成果与实际变化；限时独立比赛只支持对应比赛中的独立表现。不能据此推断陌生题、一次写对、自主找错或时间安排得当。
6. 用户已选定A版：温暖自然、像了解孩子的讲师汇报，肯定实际成果，建议自然承接。`backend/parent_style.py` 保存完整匿名文风样例及共同规则；样例仅用于口吻，不能套用其中的比赛、独立性或修改过程。

## 提示词链路检查

- 逐题诊断：内部正确性、效率及代码风格分析保留专业信息；`parent_observations` 单独写具体、通俗的表现，不以提交次数推断习惯。
- 知识评分与历年CSP预测：继续使用内部分析提示，不用A版文风改变评分或等级标准。
- 训练规划：题单选择及知识方向保留内部结构，`activity/success` 用自然中文描述练习安排，不要求一次提交通过，不把代码实现写成家长建议。
- 家长写作：独立讲师角色加完整A版样例；输入不含原始能力评分理由、提交次数或代码版本统计，只有与本期表现相关的完成情况、具体表现、条件及建议。材料中的专业语句必须重新概括。
- API请求：家长写作不附加内部分析用的通用编号结构示例；JSON Schema仍约束结构。样例没有姓名，强调事实只取自本次材料。
- 检查策略：用词和表达提醒不重试、不拦截，保留 AI 返回的完整文案；结构或报告约束错误仍可重试，纠错保留A版语气，不提醒写作者“逐项核对给定的编号”。首次生成、恢复和更新文案采用同一套规则，并记录文风版本。旧版本因措辞失败但已保存有效回复时，恢复直接复用该回复和已完成的分析。

自动测试覆盖实际API请求体、首次生成及更新文案保留措辞提示、旧失败回复恢复、带提示确认及手动改词后提示消失、比赛和课堂依据区分、新旧诊断兼容；此前真实API试写另用已有学生材料及无比赛的少量材料检查文风和样例事实混入。

家长写作使用独立的讲师角色提示，不沿用内部分析员的口吻。支持思考模式的现有模型在写作阶段开启低强度思考，用于核对完成条件和组织自然表达；连接测试仍使用快速模式。生成后，讲师预览、处理文案提醒并确认。
